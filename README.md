## Selected work

**[iam_inventory_pipeline](https://github.com/saluja-ji/iam_inventory_pipeline)**
Serverless Go pipeline that snapshots AWS IAM daily into an S3 data lake, flags risky permissions, and alerts on changes. Terraform, GitHub Actions (OIDC, no static keys), and OpenTelemetry.
`Go` `Terraform` `Lambda` `Athena` `OpenTelemetry`

**OpenTelemetry Collector pipeline**
A Go service emitting traces, metrics, and logs over OTLP to a Collector run with Docker Compose.
`Go` `OpenTelemetry` `Docker`

**[wikigo](https://github.com/saluja-ji/wikigo)**
Published Go SDK for the Wikimedia API with rate limiting, backoff, and retries. [On pkg.go.dev](https://pkg.go.dev/github.com/saluja-ji/wikigo).
`Go` `net/http`
